# Custom RISC-V Processor Core

This repository contains the design files and Verilog implementation of a custom-instruction RISC-V processor core.

## Directory Structure
- Processor_Design_Verilog: Contains the Verilog hardware implementation files (ALU, control units, registers).
- RISCV Instruction Definitions: Contains RISC-V instruction set architecture definitions and related documentation.

## Current Status
- Processor architecture core logic implemented in Verilog.
- Simulation and testing phases are ongoing.
